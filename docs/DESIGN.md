# 微信抽奖解析器 - 前端界面设计文档

## 1. 设计概述

### 1.1 设计理念

采用 **简洁现代** 的设计风格，以微信的绿色为主色调，营造轻松活泼的抽奖氛围。界面以用户真实头像为核心，通过动效突出抽奖的趣味性和仪式感。

### 1.2 设计目标

- 直观易懂：用户无需学习即可上手
- 视觉冲击：抽奖动画有戏剧性效果
- 稳定可靠：各种屏幕尺寸下表现一致
- 快速响应：操作流畅无卡顿

| 参数 | 值 | 说明 |
|------|-----|------|

### 5.4 JavaScript 动画控制器

```javascript
class LotteryAnimator {
  constructor() {
    this.phases = {
      FAST_BLINK: { start: 0, end: 1000 },
      SLOW_DOWN: { start: 1000, end: 2500 },
      FINAL: { start: 2500, end: 3500 }
    };
  }

  async start(participants, onSelect) {
    return new Promise((resolve) => {
      // 阶段1: 快速闪烁
      this.fastBlink(participants, 1000);
      
      // 阶段2: 减速
      setTimeout(() => {
        this.slowDown(participants, 1500);
      }, 1000);
      
      // 阶段3: 最终选择
      setTimeout(() => {
        const winner = onSelect();
        this.finalEffect(winner);
        resolve(winner);
      }, 2500);
    });
  }

  fastBlink(participants, duration) {
    // 100ms 间隔切换高亮
    const interval = setInterval(() => {
      participants.forEach(p => {
        p.element.style.opacity = Math.random() > 0.8 ? '0.3' : '1';
      });
    }, 100);
    
    setTimeout(() => clearInterval(interval), duration);
  }

  slowDown(participants, duration) {
    // 逐渐降低闪烁频率
    const steps = [200, 300, 400];
    let step = 0;
    
    const interval = setInterval(() => {
      participants.forEach(p => {
        p.element.style.opacity = Math.random() > 0.5 ? '0.5' : '1';
      });
      
      if (step < steps.length - 1) {
        clearInterval(interval);
        setTimeout(() => {
          // 继续更慢的闪烁
        }, steps[step]);
        step++;
      }
    }, steps[step]);
  }

  finalEffect(winner) {
    // 爆炸效果
    winner.element.classList.add('avatar-winner');
    
    // 抖动其他头像
    participants.forEach(p => {
      if (p !== winner) {
        p.element.style.opacity = '0.3';
      }
    });
  }
}
```

## 6. 状态设计

### 6.1 页面状态

| 状态 | 条件 | 显示内容 |
|------|------|---------|
| 空状态 | 无上传 | 上传区域（提示文字） |
| 加载状态 | 上传中/解析中 | 上传区域（进度条） |
| 正常状态 | 已上传且有参与者 | 头像网格 + 抽奖按钮 |
| 抽奖中状态 | 抽奖动画进行中 | 动画效果 + 禁用按钮 |
| 中奖状态 | 已抽中 | 弹窗展示中奖者 |
| 完成状态 | 所有参与者已抽奖 | 提示信息 |

```

```

#### 头像卡片
```
📦 未选中 → 🎯 候选 → 🏆 中奖 → ❌ 已移除

    [正常状态]
        │
        ├─── 点击"开始抽奖"
        │         │
        │         ▼
        │    [抽奖中] ──→ 播放动画 ──→ [中奖弹窗]
        │                          │
        │                          │ 点击"继续"
        │                          ▼
        │                      [正常状态] (中奖者已移除)
        │
        ├─── 导出结果 ──→ [导出面板]
        │
        └─── 重新上传 ──→ [空状态]
```

### 8.2 错误类型与提示

| 错误码 | 用户提示 | 持续时间 |
|--------|---------|---------|
| INVALID_FORMAT | 请上传 PNG、JPG 或 JPEG 格式的图片 | 3秒 |
| FILE_TOO_LARGE | 图片大小不能超过 10MB | 3秒 |
| NO_AVATAR | 未检测到参与者头像，请上传清晰的截图 | 持续显示 |
| OCR_FAILED | 文字识别失败，请重试 | 持续显示 |
| NO_PARTICIPANTS | 未识别到参与者信息 | 持续显示 |
| NETWORK_ERROR | 网络连接失败，请检查网络 | 持续显示 |
